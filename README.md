# 秘境对决 · Claude for Games

一款 2.5D 斜俯视角的动作 MOBA Demo：战斗手感参考《传说法师》（Wizard of Legend），地图和规则参考《英雄联盟》。全程键盘操作，用 WASD 走位，配合普攻连击、蓄力攻击、穿梭和技能战斗，不需要鼠标点击。

当前版本是 **1v1 对战电脑**，单兵线，双方各有一座外塔和一个基地水晶。

## 运行

纯浏览器 Canvas 实现，**零依赖、无需构建**。由于使用了 ES Module，需要通过本地 HTTP 服务打开：

```bash
python3 -m http.server 8000   # 或 npm start
# 浏览器打开 http://localhost:8000
```

## 操作

| 按键 | 作用 |
|---|---|
| `W` `A` `S` `D` / 方向键 | 上下左右移动（八方向） |
| `J` | 普通攻击，连按触发三段连击，第三段更重 |
| 按住 `K` | 蓄力，松开释放；蓄满时伤害、范围更大，并附加额外效果 |
| `空格` / `L` | 穿梭（短距离位移，带无敌帧，可取消攻击后摇） |
| `U` / `I`（或 `Q` / `E`） | 技能 1 / 技能 2 |
| `Esc` | 暂停 |
| `M` | 静音 |

攻击方向就是角色面朝的方向。另外有**自动吸附**：面朝方向扇形范围内如果有敌人，攻击会自动对准它。

## 英雄

三位英雄的普攻、蓄力、穿梭和技能机制各不相同：

| | 烈焰剑士（近战斗士） | 雷霆法师（远程法师） | 寒霜游侠（远程射手） |
|---|---|---|---|
| 普攻 J | 三段挥砍，带前冲和击退 | 奥术飞弹，第三段散射三发 | 冰棱箭，第三段穿透并减速 |
| 蓄力 K | **烈焰回旋**：环身 AoE，满蓄附加灼烧 | **雷光贯穿**：直线光束，满蓄眩晕 | **寒霜箭雨**：3~7 支扇形穿透箭，满蓄减速 |
| 穿梭 | 疾影步（冲刺） | 闪现（瞬移） | 翻滚（带跳跃） |
| 技能 U | **炎龙突进**：突进伤害沿途敌人，并留下火焰轨迹 | **连锁闪电**：弹射 3 个目标并减速 | **冰霜陷阱**：最多布置 2 个，踩中后定身 |
| 技能 I | **烈焰风暴**：环身火焰旋风，同时加速 | **雷暴领域**：指定区域内持续落雷 | **后跃冰爆**：原地冰霜新星，同时后跳拉开距离 |

## 对局规则

- 每 25 秒双方各出一波小兵（4 只），小兵会沿兵线推进，并随波次逐渐变强。
- 防御塔优先攻击小兵。如果你在敌方塔下攻击它的英雄，塔会转而锁定你，而且连续命中时伤害会递增。
- 外塔存活时基地水晶无敌，摧毁基地水晶即获胜。
- 英雄阵亡后会在泉水复活，复活时间随对局时长增加。在己方泉水范围内会快速回血。
- 电脑分简单、普通、困难三档，难度会影响它的反应速度、躲技能的概率、技能使用频率和预判准度。

## 代码结构

```
index.html / styles.css     菜单、暂停、结算界面
src/
  main.js                   入口：菜单、主循环、暂停与结算
  game.js                   对局逻辑：更新、碰撞、兵线、击杀与胜负
  heroes.js                 三位英雄的数据与技能实现（新增英雄从这里开始）
  ai.js                     电脑对手（输出与键盘相同的指令结构）
  combat.js                 伤害结算、命中判定（扇形 / 圆形 / 直线）、状态效果
  input.js                  键盘输入与玩家控制器
  fx.js                     粒子、刀光、闪电、冲击环、伤害数字
  audio.js                  WebAudio 程序化音效
  map.js / config.js        地图布局与全局常量
  entities/                 Unit 基类、Hero、Minion、Tower、Projectile、Zone
  render/                   渲染：预渲染地面、物件 / 角色绘制、光照、HUD
tools/sim.js                无界面 AI 对 AI 模拟，用于检查报错和数值平衡
```

**2.5D 的实现方式**：逻辑全部在地面平面 `(x, y)` 上计算，另有高度 `z`（用于跳跃、飞行物）。绘制时投影到屏幕：`(x, y * 0.62 - z)`，物体按 `y` 排序后绘制以获得前后遮挡关系。光照的做法是先给整个画面铺一层暗色，再在光源位置“挖洞”。

### 新增一位英雄

在 `src/heroes.js` 中添加一个定义对象，需要提供以下字段：

- `basic`：普攻，包括每段的时长和回调
- `charged`：蓄力攻击，回调会收到蓄力比例 `0~1`
- `dash`：穿梭，类型为 `dash`、`blink` 或 `roll`
- `skills[2]`：两个技能，包括冷却、施法时间、AI 使用距离和回调

技能回调可以使用 `hitArc`、`hitCircle`、`hitLine` 做命中判定，用 `Projectile` 发射飞行物，用 `Zone` 生成持续区域，用 `g.after()` 安排延时效果。

## 调试参数

在 URL 后面加参数：

- `?play`：跳过菜单直接开局
- `&hero=storm&enemy=frost`：指定双方英雄
- `&difficulty=hard`：指定电脑难度
- `&auto`：玩家也由 AI 控制
- `&speed=3`：加速运行

例如：`/index.html?play&auto&speed=3&hero=frost&enemy=ember`

`npm run sim` 会在无界面环境里把所有英雄组合各跑一局，输出胜负、比分和伤害。
